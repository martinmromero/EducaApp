{% comment %} Versión liviana (solo CSS, sin la maquinaria de filtros por columna) del mismo patrón "tabla → tarjetas apiladas en mobile" que usa _column_filters_assets.html (ver ese archivo para los listados que sí tienen filtros por columna vía material/column_filters.py). Para listados simples que no necesitan filtrar, incluir este archivo en vez de forzar todo el sistema de filtros solo para heredar el CSS mobile. Convención que debe respetar la página que lo incluye: - La debe tener la clase "mobile-card-table". - Cada
necesita data-label="..." calcado del correspondiente. - Opcionalmente, una celda puede marcarse como: - rt-card-title: el dato principal — se muestra grande, sin etiqueta, como título de la tarjeta. - rt-card-select / rt-card-badge: checkbox de selección o insignia corta — flotan junto al título en vez de ir como fila propia. - Por convención, la ÚLTIMA columna ("Acciones") queda separada con un borde arriba y alineada a la derecha, sin etiqueta propia. {% endcomment %}
